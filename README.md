# Reels Report Bot

Бот автоматически собирает статистику Instagram Reels и отправляет ежедневный отчёт в Telegram-группу.

## Что делает бот

Каждый день в **12:30 по времени Джакарты (WIB)** бот:

1. Запрашивает у Instagram API данные по всем Reels аккаунта.
2. Сравнивает с вчерашним снимком, вычисляет прирост просмотров.
3. Отправляет в Telegram-группу текстовый отчёт. CSV-таблица доступна по запросу — командой `/otchet`.

## Формат отчёта

**Telegram-сообщение** содержит:

- **Сводка:** суммарный прирост просмотров за сутки и общее число просмотров по всем рилсам.
- **Новые рилсы:** список рилсов, впервые появившихся с прошлого отчёта (до 20 штук в сообщении, остальные — в CSV).
- **Топ-10 по приросту:** рилсы с наибольшим ростом просмотров за период со ссылками.

**CSV-файл** по команде `/otchet` (`;`-разделитель, UTF-8 с BOM для Excel) содержит все рилсы, отсортированные по приросту:

| Ссылка | Дата публикации | Просмотров всего | Прирост за период |
|--------|----------------|-----------------|------------------|
| https://... | 15.07.2025, 10:00 | 12 345 | +890 |

> Первый запуск («базовый замер») сохраняет начальную точку отсчёта; прирост появится в следующем отчёте.

## Где хранятся данные

Ежедневные снимки (snapshot) сохраняются в **Vercel Blob** в формате JSON. Каждый файл содержит список рилсов с просмотрами на момент замера. Данные хранятся неограниченно долго и доступны через панель Vercel → Storage → Blob.

## Крон-расписание

Маршрут `/api/report` вызывается Vercel Cron по расписанию `30 5 * * *` UTC, что соответствует **12:30 WIB** (Asia/Jakarta, UTC+7).

> **Примечание:** на бесплатном тарифе Vercel (Hobby) крон может срабатывать с задержкой относительно 12:30 — период в отчёте всё равно считается по фактическому времени запуска.

Ручной запуск (с токеном `CRON_SECRET`):

```bash
curl -H "Authorization: Bearer $CRON_SECRET" \
  https://<project>.vercel.app/api/report
```
