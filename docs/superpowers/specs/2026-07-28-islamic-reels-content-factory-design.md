# Дизайн: фабрика автогенерации рилсов (исламский контент, Bahasa Indonesia)

Дата: 2026-07-28
Статус: утверждён (брейншторм), готов к плану сборки

## Цель
Автоматизировать выпуск **безликих рилсов с текстом на экране** (стиль @daristeppe /
@istiqomah.tahajud): фон-сток + цитата на экран + нашид. Цель — **1 оператор выпускает
30–50 рилсов/день** (человек только на QA, не на сборке). Контент льёт охват → сообщество →
(после релиза) скачивания приложения Qurany.

## Зафиксированные решения (брейншторм)
1. **Формат:** рилсы с текстом на экране (не статичные карточки).
2. **Фон:** бесплатный сток (Pexels / Pixabay / Mixkit) — природа, мечети, каллиграфия.
3. **Текст:** гибрид — LLM **переупаковывает готовый смысл из проверенного банка**
   (не выдумывает) + QA. Причина — богословская точность (нельзя выдуманных хадисов).
4. **Автоматизация:** полный автомат пачками, человек = QA в конце.
5. **Объём:** ~30–50/день, облачный рендер.
6. **Аудио:** нашид **вокал-онли / эмбиент, без инструментала** (нишевая красная линия).
7. **Подход к сборке:** **готовый n8n-шаблон + Creatomate + Google-таблица** —
   не строим оркестратор с нуля и не берём чёрный-ящик SaaS (тот сам генерит сценарий
   → риск для религии). Середина: готовый воркфлоу + наш контроль текста.

## Архитектура

```
GOOGLE-ТАБЛИЦА (банк цитат)
   ↓  n8n (cron) берёт N строк со статусом "ready"
n8n WORKFLOW:
   1. Читает строку (проверенная цитата + тема)
   2. LLM (Claude Haiku): оформляет текст-на-экран + хук-капшен из готового смысла
   3. Pexels API: вертикальный (9:16) клип по теме + дедуп против использованных
   4. Берёт нашид из библиотеки (Drive/Blob), ротация
   5. Creatomate: рендер шаблона {клип, текст, нашид} → MP4 (1080×1920, 30fps, H.264)
   6. Сохраняет MP4 + метаданные в папку review; строка → "rendered"
   7. QA: человек смотрит папку → approve → "approved"
   8. Авто-постинг (approved) → IG по расписанию (IG Graph API / Publer / Buffer)
```

## Компоненты (изолированные, каждый — одна задача)

1. **Банк цитат (Google-таблица)** — источник истины по тексту.
   Колонки: `id | смысл_источник | ссылка_на_источник | тема | текст_на_экран | статус | video_url | использован`.
   Статусы: `draft → ready → rendered → approved → posted`. Растёт со временем.
   *Зависимости: нет. Курируется человеком (богословская проверка на входе).*

2. **Text-генератор (LLM node, Claude Haiku)** — берёт `смысл_источник` → выдаёт
   короткий цепляющий `текст_на_экран` (Bahasa) + хук для капшена. **Не изобретает** —
   только оформляет готовый смысл. *Зависит от банка.*

3. **Footage-picker (Pexels API node)** — запрос по `тема` → вертикальный клип 9:16,
   дедуп против колонки «использован». *Зависит от темы строки.*

4. **Audio-picker** — библиотека нашидов (вокал-онли, лицензионные) на Drive/Blob,
   ротация. *Зависимость: разовый лицензионный пак 5–10 треков.*

5. **Renderer (Creatomate)** — один бренд-шаблон (шрифт/позиция/анимация текста);
   заполняется `{клип, текст, нашид}` → MP4. *Зависит от 2,3,4.*

6. **Review-очередь** — папка Drive/Blob с MP4 + метаданными; QA approve/reject
   переводит статус строки. *Зависит от renderer.*

7. **Авто-постинг** — одобренные → IG по расписанию. Вариант A: наш IG Graph API
   (уже есть инфра). Вариант B: Publer/Buffer. *Зависит от review-очереди.*

8. **Оркестратор (n8n cron)** — цикл по пачке, учёт лимитов Creatomate/IG,
   ретраи, логи. *Готовый шаблон, адаптируем.*

## QA-гейт
- **Авто:** спека 1080×1920 / 9:16 / 30fps / длительность 8–20с; MP4 не битый; дедуп клипа.
- **Ручной (выборка + флаги):** уместность кадра, читаемость текста, что смысл не искажён
  при оформлении.
- **Нишевые красные линии:** нет изображений Пророков; корректная атрибуция аята/хадиса
  (гарантируется банком); аудио — вокал-онли, без инструментала; скромность кадров.
- Богословский риск **низкий**, т.к. текст идёт из проверенного банка, а LLM только оформляет.

## Порядок сборки
1. Собрать **банк цитат** (таблица, 50–100 проверенных записей на старт).
2. **Библиотека нашидов** (5–10 вокал-онли треков, лицензия).
3. **Дизайн Creatomate-шаблона** (бренд-стиль текста/анимации).
4. Импорт + адаптация **готового n8n-шаблона** (Таблица → Pexels → Creatomate → Drive).
5. **Тест-пачка** в dry-режиме (рендерит, не постит).
6. Добавить **QA-шаг** (review-папка + смена статуса).
7. Добавить **авто-постинг** одобренных.

## Обработка ошибок
- API-сбои (Pexels/Creatomate/IG): ретрай с backoff, при исчерпании — строка в статус
  `error` + лог, не блокирует пачку.
- Нет подходящего клипа по теме → фолбэк на общий пул тем.
- Дедуп клипов и текстов, чтобы не плодить одинаковое.
- Лимиты Creatomate/IG: очередь с учётом квоты.

## Тестирование
- Dry-режим: генерация без постинга, ручная приёмка пачки.
- Пилот: 1 неделя, 10–15 рилсов/день на 1 аккаунт, замер охвата → потом масштаб до 50.

## Допущения / открытые пункты
