## Визуальная система (выведена из логотипа Qurany и UI приложения)

- Фон: кремовый «бумажный» (~#F4F1E9), как в приложении Qurany.
- Основной: тёмно-изумрудный (~#134A34) — из логотипа Qurany (текст, плашки).
- Акцент: золото/амбер (~#D9A441) — из обложки суры в приложении (цифры, орнамент, линии).
- Инверсные слайды (обложка, финал): изумрудный фон, кремовый текст.
- Типографика: латиница/кириллица — спокойный гуманистический гротеск + антиква для цитат;
  арабский — ТОЛЬКО живой текст каллиграфическим шрифтом (Amiri / Noto Naskh Arabic),
  никакой ИИ-генерации арабских надписей (риск искажения букв недопустим для аудитории улемов).
- Орнамент: сдержанные геометрические рамки/паттерны, перекликающиеся с шестиугольником логотипа.
