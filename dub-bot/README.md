# Telegram-бот для дубляжа видео RU → Bahasa Indonesia

Бот принимает видео с русской речью и возвращает тот же ролик, озвученный на индонезийском через ElevenLabs Dubbing API.

## Архитектура

Ключевая особенность: **видео не загружается через бота**. Telegram ограничивает загрузку 20 МБ на скачивание и 50 МБ на отправку, а реальные ролики занимают ~400 МБ.

Вместо этого:

1. Пользователь отправляет `/dub` боту.
2. Бот возвращает ссылку на страницу загрузки (действительна 30 минут).
3. Пользователь открывает ссылку в браузере и выбирает видео из галереи.
4. Браузер загружает файл напрямую в Vercel Blob (без ограничений размера).
5. Функция `POST /api/dub/start` отправляет видео в ElevenLabs по публичной ссылке и сохраняет ID задачи.
6. Функция `GET /api/dub/tick` опрашивает статус дубляжа каждые 10 секунд до готовности.
7. Когда результат готов, бот отправляет видео в Telegram по размеру:
   - ≤20 МБ: по ссылке (Telegram скачает сам)
   - ≤50 МБ: загрузкой multipart через нашу функцию (повышаем потолок)
   - >50 МБ: сообщение со ссылкой на Blob

После успешного дубляжа исходный файл удаляется из Blob.

## Команды бота

- **`/dub`** — получить ссылку для загрузки видео. Ссылка действует 30 минут.
- **`/status`** — показать активные задачи. Заодно переподхватывает задачи, если цепочка опроса оборвалась (см. ниже).
- **`/help`** — справка.

## Переменные окружения

Все переменные обязательны.

| Переменная | Откуда | Назначение |
| --- | --- | --- |
| `TELEGRAM_DUB_BOT_TOKEN` | @BotFather | Токен бота Telegram. |
| `TELEGRAM_ALLOWED_CHAT_IDS` | ручная | Список chat_id, через запятую. Только эти чаты могут использовать бота. |
| `TELEGRAM_WEBHOOK_SECRET` | ручная (криптографический) | Секрет для проверки вебхука Telegram (`setWebhook`). Генерируется `openssl rand -hex 32`. |
| `ELEVENLABS_API_KEY` | https://elevenlabs.io/account | Ключ API ElevenLabs для дубляжа. |
| `DUB_TOKEN_SECRET` | ручная (криптографический) | Секрет для подписи токенов загрузки (HMAC). Генерируется `openssl rand -hex 32`. |
| `DUB_BASE_URL` | ручная | Прод-URL проекта (например, `https://dub-bot-xyz.vercel.app`). Добавляется после первого деплоя. |
| `CRON_SECRET` | ручная (криптографический) | Секрет для cron-задач (очистка Blob). Генерируется `openssl rand -hex 32`. |
| `BLOB_READ_WRITE_TOKEN` | Vercel | Выдаётся Vercel автоматически при подключении Blob Storage. |

## Как работает опрос (polling)

ElevenLabs Dubbing API не имеет вебхуков о завершении — только опрос статуса. Дубляж длится дольше 300 секунд (лимит функции Vercel), поэтому используется цепочка само-вызовов:

1. Пользователь нажимает «Дублировать» → функция `POST /api/dub/start` создаёт задачу в ElevenLabs и вызывает `GET /api/dub/tick`.
2. Функция `tick` опрашивает ElevenLabs каждые 10 секунд (~240 сек максимум, чтобы оставить время на доставку).
3. Если результат не готов и бюджет вызова не исчерпан → `tick` вызывает сам себя и завершается.
4. Если результат готов → доставляет видео в Telegram и удаляет исходник.
5. Если бюджет исчерпан, но результат не готов → вызывает сам себя в следующий раз.

**Если цепочка оборвётся** (ошибка Vercel, сетевой сбой): отправьте `/status` в боте — это переподхватит задачу и продолжит опрос.

Дневная cron-задача (`POST /api/cleanup` в 04:00 UTC) удаляет зависшие задачи старше 30 минут и очищает Blob от ненужных файлов.

## Стоимость

- **Расход:** ~2000 кредитов ElevenLabs на минуту видео (проверено: 334 кредита за 10-секундный ролик).
- **Free-тариф:** 10 000 кредитов в месяц ≈ 5 минут дубляжа. Также добавляет водяной знак.
- **Водяной знак:** определяется автоматически при создании задачи в зависимости от tier подписки (`watermark: tier === "free"`). Апгрейд ElevenLabs снимет знак без изменений в коде.

## Подключение вебхука Telegram

После деплоя нужно подключить вебхук для получения сообщений:

```bash
curl -sS -X POST "https://api.telegram.org/bot<ТОКЕН>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url":"https://<домен>/api/telegram",
    "secret_token":"<TELEGRAM_WEBHOOK_SECRET>",
    "allowed_updates":["message"]
  }'
```

Заменить:
- `<ТОКЕН>` → значение `TELEGRAM_DUB_BOT_TOKEN`
- `<домен>` → прод-URL проекта (из Vercel, например `dub-bot-xyz.vercel.app`)
- `<TELEGRAM_WEBHOOK_SECRET>` → значение переменной окружения

Проверить статус:

```bash
curl -sS "https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo"
```

Должны увидеть:
- `"url"` совпадает с установленной ссылкой
- `"last_error_message"` отсутствует или пустой

## Отладка

При проблемах смотреть:

1. **Логи Vercel:** `vercel logs <домен> --follow` (потоковый вывод)
2. **Команда `/status`:** если цепочка опроса оборвалась, `/status` её оживит и покажет текущие задачи.

Типичные проблемы:

- **Видео не загружается:** проверить размер (ограничение браузера) и соединение.
- **Задача зависла в «dubbing»:** обычно ElevenLabs медленно работает. Отправить `/status`, чтобы переподхватить.
- **Ошибка 403 при дубляже:** free-тариф исчерпал кредиты — нужен апгрейд на ElevenLabs.
- **Вебхук не получается:** убедиться, что `secret_token` совпадает с `TELEGRAM_WEBHOOK_SECRET`, и проверить доступность домена.

## Процесс развёртывания

1. Создать бота в @BotFather и получить токен.
2. Узнать свой `chat_id` (отправить боту сообщение, открыть `https://api.telegram.org/bot<TOKEN>/getUpdates`).
3. Создать проект на Vercel и подключить Blob Storage.
4. Прописать переменные окружения (см. таблицу выше).
5. Задеплоить: `vercel deploy --prod`
6. Подключить вебхук curl-командой (см. выше).
7. Провести смоук-тест на коротком ролике (15 сек, русская речь).

Полная инструкция в задаче Task 11 в `.superpowers/sdd/2026-08-13-telegram-dubbing-bot/task-11-brief.md`.
